Limites por categoria

Valor máximo, em USDC, que o agente pode aprovar sozinho para cada categoria. Acima disso, a solicitação sempre é escalada para revisão humana, não importa o quanto o modelo confie nela.

Limites de decisão

Controlam quando o agente aprova sozinho, aprova com valor reduzido, ou escala para um humano.

Critérios de avaliação (Kev / Jev)

O texto de cada nível é o que o modelo de decisão lê para pontuar confiança, urgência e importância. Cada critério precisa de 2 a 10 níveis.
